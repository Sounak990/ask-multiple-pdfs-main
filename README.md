# ReaderBuddy: Smart PDF Assistant

> This project is based on the "Chat with Multiple PDFs" tutorial, which you can find on [YouTube](https://youtu.be/dXxQ0LR-3Hg).

ReaderBuddy is an interactive web application built with Streamlit that allows users to upload multiple PDF documents and engage in a natural language conversation about their content. The application leverages a Retrieval-Augmented Generation (RAG) pipeline to provide accurate, context-aware answers based solely on the information within the uploaded documents.

## Core Features

-   **Multiple PDF Upload:** Upload one or more PDF files simultaneously.
-   **Text Extraction:** Automatically extracts and processes text from all pages of the uploaded PDFs.
-   **Conversational AI:** Ask questions in plain English and receive answers generated by a large language model.
-   **Chat History:** Maintains conversation history for follow-up questions and context.
-   **Custom UI:** A clean and user-friendly chat interface for a smooth user experience.

## How It Works (Architecture)

![MultiPDF Chat App Diagram](https://raw.githubusercontent.com/alejandro-ao/ask-multiple-pdfs/main/docs/PDF-LangChain.jpg)

The application follows a modern RAG pipeline to achieve its functionality:

1.  **PDF Loading & Text Extraction:** User-uploaded PDFs are processed using `PyPDF2` to extract raw text content.
2.  **Text Chunking:** The extracted text is divided into smaller, manageable chunks using `LangChain's CharacterTextSplitter`. This is crucial for the embedding model's context window and for effective retrieval.
3.  **Embedding & Vector Storage:** Each text chunk is converted into a numerical vector representation (embedding) using `HuggingFace's instructor-xl` model. These embeddings are then stored in a `FAISS` in-memory vector store for efficient similarity searching.
4.  **Semantic Search & Retrieval:** When a user asks a question, it is also converted into an embedding. The `FAISS` vector store performs a similarity search to find the most relevant text chunks from the documents.
5.  **Response Generation:** The user's question and the retrieved text chunks are passed to an OpenAI language model via `LangChain's ConversationalRetrievalChain`. The model uses this context to generate a coherent and accurate answer. The chain also manages conversation memory.
6.  **Frontend Display:** The entire conversation is displayed in the Streamlit web interface using custom HTML templates for styling.

## Technology Stack

-   **Frontend:** Streamlit
-   **Backend / AI Orchestration:** LangChain
-   **Language Model (LLM):** OpenAI (`ChatOpenAI`)
-   **Embedding Model:** Hugging Face Instructor Embeddings (`hkunlp/instructor-xl`)
-   **Vector Store:** FAISS (Facebook AI Similarity Search)
-   **PDF Processing:** PyPDF2
-   **Dependencies Management:** pip, python-dotenv

## Setup and Installation

Follow these steps to run the application locally.

**1. Clone the Repository**
git clone <your-repository-url>
cd <repository-folder>

text

**2. Create a Virtual Environment (Recommended)**
python -m venv venv
source venv/bin/activate # On Windows, use venv\Scripts\activate

text

**3. Install Dependencies**
The required packages are listed in `requirements.txt`. Install them using pip:
pip install -r requirements.txt

text

**4. Set Up Environment Variables**
You need an OpenAI API key. Create a file named `.env` in the root of the project directory and add your key:
OPENAI_API_KEY="your_openai_api_key"

text

## Usage

Once the setup is complete, run the application using the Streamlit CLI:

streamlit run app.py

text

The application will open in your default web browser. You can then upload your PDFs via the sidebar and start asking questions.
